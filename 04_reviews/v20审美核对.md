# v20实装完整版：审美核对

同一助手按既有住宅设计技能审查，未虚构独立专家或客观评分。对照业主选定的自然现代日式、干净暖白浅木、局部深木绿蓝，以及摄影感光影；主要证据是`v20-complete-native`原生图和`v20-complete-photographic`最终八图。

| 维度 | 可见证据及结论 |
|---|---|
| 色彩 | 客厅暖白留白、浅木和米灰占主体；奶黄限于走廊下柜。胡桃U餐面和办公压顶增加深浅层次，绿蓝点色没有扩成大面积墙色。 |
| 材料 | 低绒织纹地毯与细织沙发增加触感，胡桃与浅木分工明确。AI木纹、叶片和反射不是实物样板；柜门／墙漆实样仍未定。 |
| 比例与秩序 | 餐柜四段式、齐平U台面和圆端保留；新鞋柜端部、柜体顶部与窄收口减少碎片感。新增设备带集中在走廊，不绕客厅做连续装饰框。 |
| 光影 | 四区摄影概念以斜向日光、柔和接触阴影与局部柜内暖光形成层次。原生夜景保留明暗差，无中心主灯。未进行照度计算。 |
| 视觉焦点 | 电视墙保持干净；主次焦点来自落地窗、沙发／地毯和深木餐岛。书柜与办公高台在后侧形成次层，不另加高墙或阳台端栏杆。 |
| 氛围一致性 | 日式的自然材质、低茶席、纸灯、柔弧端部得到延续；到顶柜与平整哑光墙仍是直线骨架。办公B为预览，尚不当作业主最终材质选择。 |

本轮发现并修正：餐厅球面图漏画纸灯；阳台摄影近景／球面多画茶席地毯；入口球面多画外部家具与不正确洗烘反射。每张作一次局部修正并回读保存副本。微透视、窗景、反射和细小道具仍可能与实体有差异，以模型为准。四点原生球面与摄影概念均留档，不把AI图当毫米准确模型。
