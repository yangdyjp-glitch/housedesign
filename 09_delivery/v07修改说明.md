# v07：绿植角、入户柜与单屏办公

本版接续现代日式暖色圆角主模型，保留既有户型关系、已选方案和其余家具位置。单位为mm；上南下北、左东右西沿用用户标注。

## 本次落地

- 阳台左侧与面向电视时的电视右侧合成一个绿植角，三盆高低组合，建议包络高度1500 / 1000 / 650。电视屏幕及柜门前留空，盆器采用统一暖灰米色。
- 沙发、茶几向图片下方平移500；脚凳同步跟随，避免原位置与下移的茶几相交。贵妃位仍在阳台端。移动量为本轮设计建议。
- 入户按红色L区增设350深、2400高的鞋柜与储物立柜。长边1533，其中末端350为封闭盲角；短边921。柜门有效面、踢脚和木色顶板已建模。
- 阳台右端下洗上烘，正面朝图左。单台先以600宽×650深×850高包络布置，中间安装件暂占30，上部设备底部离地880。选中任一设备时，交互模型中两台一起移动。
- 双人桌保留2400长×700深×750高，圆角R70，暂配一把椅子，方向仍朝电视。桌上只有一台34英寸超宽屏、一套键鼠，并配小绿植、台灯、笔筒、水杯；其余桌面留空。小配件随桌体移动。
- 原85英寸电视、四椅靠墙餐桌、入户通长柜及置物格、书柜、暖白浅木与苔绿/深蓝点缀沿用。聊天内布局视图也同步了桌角、墙角饰面和配色。

## 可操作模型

- 共21件整件家具：可悬停看长宽高、点击选中、拖动或按100mm步进移动、撤销和恢复保存状态。上方烘干机在平面图中遮住下方洗衣机，可切换立体视图或从列表选中。
- 办公桌提示750为桌体高度；电视提示1100为机身高度，均不把安装位置或桌上物品算入家具高度。植物长宽为含叶冠的方案包络。
- Blender主模型为`06_blender/home-main-v07.blend`，完整墙体和门窗保留；两张低墙图是临时观察渲染，不改变正式主模型。
- 100mm是操作步长。房屋尺寸继续以草图拟合记录为依据，不能把移动步长当作现场测量精度。

## 本次核对与使用余量

| 位置 | 当前方案值 | 结论 |
|---|---:|---|
| 沙发背至书桌前沿 | 500 | 沿用X向关系，北移只改变Z位置 |
| 常规沙发前沿至茶几 | 500 | 组合平移后保留 |
| 贵妃端至茶几端 | 450 | 组合平移后保留 |
| 入户短过道，鞋柜门关闭 | 921 | 门扇方向、打开时的活动区待核 |
| 办公椅最外缘至书柜 | 408 | 既有局部窄处保留；后续可另行调整 |
| 脚凳后缘至客卫前墙 | 470 | 新版局部窄处；主通行从左侧绕行，不将470当成主通道宽 |
| 脚凳左缘至电视柜正面 | 2600 | 模型中留有主通行空间 |
| 洗烘设备后部至右墙 | 50 | 方案预留，不能替代具体产品要求 |

按组成零件的三维包围盒核对，家具与墙体相交0组、不同家具之间相交0组。悬停/点击/100mm步进逐件通过；茶几实际鼠标拖动100mm、撤销、旧版状态迁移、320px布局和深色模式检查通过。

## 尺寸参考与待深化

34寸机壳810×90×370为近似占位，参考[戴尔官方34寸规格](https://www.delltechnologies.com/asset/en-us/products/electronics-and-accessories/technical-support/dell-34-curved-gaming-monitor-s3422dwg-product-data-sheet.pdf)的807.9×85.81×366.36，未锁定品牌或型号。洗烘650深的占位参考含机门的常见外廓：[洗衣机官方尺寸图](https://media3.bosch-home.com/Documents/specsheet/en-GB/WGG24409GB.pdf)、[烘干机官方尺寸](https://www.bosch-home.co.uk/supportdetail/product/WQG24509GB/09)。30mm安装件仅为本方案占位，叠放件、检修、供电、排水和机门开启空间按最终机型及现场条件深化。

入口已按用户定位在图左下，精确门洞、门扇开向、实际净高和图纸未闭合尺寸仍在待核清单。绿植为模型意向，具体品种需结合窗边日照、养护习惯选定。
